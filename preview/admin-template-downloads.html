Naya template card kaise add karein?

  1. Bakery me card duplicate karein → heading/description badlein → link text “Download Template” rakhein → Update.
  2. Yahan + Add template → Template name (wahi heading) + Card keywords + file upload.
  3. Save → WP-Optimize se cache purge → page par test.
